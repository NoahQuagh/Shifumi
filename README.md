# Shifumi 

https://noahquagh.github.io/Shifumi/

Un jeu classique de **Shifumi** développé en JavaScript, HTML et CSS.

---

## Fonctionnalités

- **Joueur vs Ordinateur :** Choisissez entre Pierre, Feuille ou Ciseaux et affrontez l'IA.
- **Gestion du Score :** Suivi en temps réel des victoires, défaites et égalités.
- **Responsive Design :** Interface optimisée aussi bien pour ordinateur que pour mobile.
- **Réinitialisation :** Possibilité de remettre les scores à zéro pour recommencer une partie.

---

## Technologies Utilisées

- **HTML5** 
- **CSS3**
- **JavaScript**
